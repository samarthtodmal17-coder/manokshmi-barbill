Excise Daily Stock Register

Opening / Receipts / Sales / Closing for all excise-tracked items on the selected date. Maharashtra excise sales reporting on the SCM portal is a daily requirement -- use this alongside "Export for SCM Sales Upload" below every day, not just at month-end.

Choose a date and run the register.

Export for SCM Sales Upload

Generates a .xlsx in the exact format the Excise SCM portal expects for Transaction Entry > Multiple Sales Entry -- ready to upload as-is. Only items with an SCM Item Code set (Setup > Items > Brand Info, or the bulk import tool) are included. If an item has "Bottles per Case" set in Brand Info, sold quantity splits into Case + Loose Bottle automatically; otherwise everything goes into Loose Bottle.

This hasn't been confirmed against a real portal upload yet -- do a small test upload (one day's data) before relying on it for a full month's filing.

Activity Log

GST vs Excise Revenue Split

A single bar bill often mixes GST-taxable food with excise-only liquor. This splits revenue between the two so your GST filing and excise return can each work from the right number, instead of one combined bill total. Discount, service charge, and tax are allocated proportionally to each bill's food vs. liquor share.

Choose a date range and run the report.

Data & Performance

Every sale, purchase, and stock change is stored in this browser. Over many months that history grows, and can eventually slow the app down or run out of space. Archiving moves old detail out (after you've backed it up) while keeping today's stock and balances exactly correct.

Archiving downloads a snapshot file automatically -- select that file here to merge those bills, purchases, wastage, and stock-log detail back into the live app.

Erase All Data (Fresh Start / New Owner)

Wipes every bill, item, stock figure, and setting in this browser back to a blank template. Use this to hand the same file to a different bar owner, or -- just as validly -- to start completely fresh yourself after years of use (e.g. once records that old are no longer needed and archiving alone isn't what you want). This does not delete your GitHub files or any downloaded backups -- only what's stored in this browser.
